Accounts

Saved on this server in settings.json and handed to the tools on each run. Tokens and passwords are never shown again after saving; leave one blank to keep it.

ListenBrainz

Your listening history. The token is on your ListenBrainz settings page; Crate needs it to scrobble, and it helps pick preview songs.

Last.fm optional

Extra listening history, and scrobbling. Get an API key and shared secret by creating a Last.fm API account (any name and description; leave the callback URL blank). Leave the API key blank to skip Last.fm.

Navidrome optional

Your library, so picks skip albums you already have. Leave the address blank to skip it.
